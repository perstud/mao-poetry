# 毛主席诗词学习网

一个可离线阅读的中文诗词网站，收录毛泽东诗词 74 篇、共 78 首。可按创作时期、编次浏览，也可搜索篇名、诗句、题记、原注和编者考辨，查看高亮片段并定位原文。书目及图像来源见[关于本站](about.html)。

## 本地浏览

用浏览器打开 `index.html` 即可。页面、`assets/` 和 `js/` 需保持现在的相对位置。内容维护见[使用说明](使用说明.md)。

## 发布到 GitHub Pages

1. 将本目录的内容推送到 GitHub 仓库的 `main` 分支，让 `index.html` 位于仓库根目录。
2. 在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，然后点 **Save**。
3. 等待首次部署完成，点击同一页面的 **Visit site** 打开网站。以后推送到 `main` 的修改会自动发布。

本站没有构建步骤，也不需要配置数据库、域名或密钥。
